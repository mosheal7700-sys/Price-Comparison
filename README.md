# הסל הזול

אתר להשוואת מחירי סל קניות בין רשתות וסניפים, לפי עיר. האתר רץ ב-GitHub Pages והמחירים מתעדכנים אוטומטית.

## איך זה עובד

1. **GitHub Actions** מריץ את `collect.py` כל 4 שעות (ובלחיצה ידנית).
2. הסקריפט מוריד מכל רשת את קבצי המחירים שהיא מחויבת לפרסם לפי חוק שקיפות מחירים (באמצעות הספרייה [israeli-prices](https://pypi.org/project/israeli-prices/)), מתאים מוצרים לפי ברקוד וכותב קובצי JSON לכל עיר.
3. אותו תהליך מפרסם את `index.html` יחד עם תיקיית `data/` ל-GitHub Pages.
4. בכל פתיחה של האתר, הדפדפן טוען את קובצי ה-JSON האחרונים. הכפתור "רענן מחירים" טוען אותם שוב.

אם הקבצים לא קיימים (למשל בפתיחת `index.html` ישירות מהמחשב), האתר עובד במצב הדגמה עם נתוני דוגמה.

## התקנה

1. העלה למאגר, בשורש: `index.html`, `collect.py`, `config.json`, `requirements.txt`, `README.md`.
2. צור את הקובץ `.github/workflows/update.yml`: Add file ← Create new file, הקלד את הנתיב המלא בשם הקובץ והדבק את התוכן.
3. Settings ← Pages ← Build and deployment ← Source: **GitHub Actions**.
4. לשונית Actions ← "עדכון מחירים ופרסום האתר" ← Run workflow.
5. אחרי כמה דקות האתר מתעדכן. כדי לראות מה נאסף, פתח `<כתובת האתר>/data/index.json`: השדה `chains` מראה מה מצב כל רשת.

## הגדרות (`config.json`)

- `chains`: הרשתות לאיסוף, לפי הקוד שלהן בספרייה.
- `cities`: כ-90 ערים. לכל עיר `key` באנגלית, `name` להצגה, `match` עם מילים שמחפשים בעיר או בכתובת של הסניף (הזיהוי מתעלם ממקפים ומגרשיים), ו-`enabled`.
  - עיר עם `"enabled": true` נאספת ומופיעה באתר. ברירת המחדל: 20 הערים הגדולות.
  - כדי להוסיף עיר מהרשימה, משנים את `enabled` ל-`true`. כדי להוסיף עיר שלא ברשימה, מוסיפים שורה חדשה באותו מבנה.
  - כל עיר מוסיפה זמן ריצה (עד 16 קבצי מחירים). אם התהליך ארוך מדי, אפשר להפעיל פחות ערים או להקטין את `stores_per_chain`.
- `stores_per_chain`: כמה סניפים לכל רשת בכל עיר.
- `min_chains`: בכמה רשתות לפחות צריך להימצא מוצר עם ברקוד כדי להופיע (1 = כל המוצרים).
- `max_products`: כמה מוצרים עם ברקוד בקטלוג של כל עיר, הנפוצים ביותר קודם.
- `include_unbarcoded`: האם לאסוף גם מוצרים בלי ברקוד, כמו ירקות, פירות ודגים לפי משקל.
- `loose_min_chains`: בכמה רשתות לפחות צריך להופיע שם זהה של מוצר בלי ברקוד (1 = כל המוצרים, גם אם הם נמצאים רק ברשת אחת).
- `max_loose`: כמה מוצרים בלי ברקוד בקטלוג של כל עיר.

## בעיות ידועות

- חלק מאתרי הרשתות חסומים מחוץ לישראל. שרתי GitHub נמצאים בחו״ל, ולכן רשת שנכשלת מופיעה באתר כ"לא התקבל עדכון", ונשמרים הנתונים הקודמים שלה כ"נתונים ישנים". הפתרון הוא להריץ את התהליך על מחשב בישראל: להתקין [self-hosted runner](https://docs.github.com/en/actions/hosting-your-own-runners) ולהגדיר במאגר משתנה בשם `RUNNER_LABEL` עם התווית שלו.
- בסניפים שבהם העיר לא מופיעה בקובץ הסניפים או בכתובת, הסניף לא יזוהה. כדאי להוסיף מילים ב-`match`.
- מוצרים בלי ברקוד (ירקות, פירות, דגים) מותאמים בין רשתות לפי השם בלבד, אחרי הסרת מספרים ויחידות. רשת שקוראת למוצר בשם אחר תופיע כשורה נפרדת, ובהשוואה שלה יסומן "אין במלאי" בשאר הרשתות. כברירת מחדל (`loose_min_chains: 1`) מוצגים כל המוצרים, גם אלה שנמצאים רק ברשת אחת. כשיש כמה וריאנטים של אותו שם באותו סניף, נלקח הזול שבהם. בהרצה הראשונה כדאי לבדוק אם החיפוש מוצא את מה שאתה צריך. אם הרשימה ארוכה מדי, אפשר להעלות את `loose_min_chains` ל-2.
- מחירי מבצעים אינם כלולים.
- ב-GitHub, תזמון אוטומטי במאגר ציבורי מושבת אחרי כ-60 יום בלי פעילות במאגר. אפשר להפעיל אותו מחדש בלשונית Actions.
