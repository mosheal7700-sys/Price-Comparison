    ניהול ערים

    הוספה והסרה של ערים משנות את הקובץ config.json במאגר (השדה enabled הופך ל-true או false), והאיסוף הבא מתחיל לבד. זה דורש מפתח גישה פרטי למאגר, ששמור רק בדפדפן הזה.

    1. ב-GitHub, בתפריט הפרופיל: Settings > Developer settings > Personal access tokens > Fine-grained tokens > Generate new token.
    2. בחר את המאגר הזה תחת Repository access > Only select repositories, ותחת Permissions > Contents בחר Read and write. מומלץ לקבוע תפוגה.
    3. הדבק את המפתח כאן ולחץ "התחבר".
